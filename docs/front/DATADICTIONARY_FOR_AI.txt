================================================================================
关键业务规则
================================================================================

1. 用户管理:
   - 登录: 支持用户名/密码、手机号/验证码登录
   - 角色: USER(普通用户) / ADMIN(管理员)
   - 认证: JWT Token + 拦截器权限控制
   - Token Header: Authorization: Bearer <token>

2. 商品管理:
   - 支持分类树形展示(一级/二级分类)
   - 支持全文检索(MyBatis FULLTEXT)
   - 热销/新品/热门标签
   - 支持按价格区间、销量排序

3. 订单流程:
   - 订单状态: 待支付 -> 已支付 -> 已发货 -> 已完成
   - 可支持取消、退款状态
   - 使用订单号作为业务唯一标识
   - 支持使用优惠券和运费计算

4. 秒杀设计:
   - 基于时间窗口的限时活动
   - 支持每人限购数量限制
   - 使用 Redis 预减库存 + RabbitMQ 异步下单
   - 使用分布式锁防止超卖

5. 优惠券:
   - 支持满减券和折扣券两种类型
   - 支持有效期时间范围限制
   - 记录用户领取/使用状态
   - 支持库存管理
