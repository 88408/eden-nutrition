Eden 商家后台管理系统 API 文档 (v1.0)
基础路径: https://api.eden-store.com/v1
内容类型: application/json
认证方式: Authorization: Bearer <token>
基础路径：https://api.eden-store.com/v1

1. 认证模块 (Auth)
1.1 用户登录
接口: POST /auth/login
接口 ： POST /auth/login

描述: 用户通过用户名和密码登录系统。
请求体:
code
JSON
{
  "username": "admin",
  "password": "password123"
}
响应体:
code
JSON
{
  "token": "mock-jwt-token-123",
  "user": {
    "id": "1",
    "username": "admin",
    "role": "admin",
    "avatar": "https://..."
  }
}

2.1 获取统计概览
接口: GET /dashboard/stats

接口 ： GET /dashboard/charts/category-distribution

JSON

6. 秒杀活动模块 (Seckill)
6.1 获取活动列表

接口 ： GET /seckills

响应体:
code
JSON
[
  {
    "id": 1,

接口: POST /seckills/:id/publish (发布) / DELETE /seckills/:id (删除)
接口 ： POST /seckills/：id/publish （发布） / DELETE /seckills/：id （删除）

7. 数据字典与枚举
7.1 商品状态 (status)
1: 上架中 (Online)
0: 已下架 (Offline)
7.2 订单状态 (orderStatus)
待发货: 待处理
已发货: 运输中
已完成: 订单结束
已取消: 用户或系统取消
说明:
所有涉及图片的接口，前端目前支持 base64 预览，后端建议返回 URL。
批量编辑接口建议支持局部更新。
认证 Token 需在所有请求的 Header 中携带。
