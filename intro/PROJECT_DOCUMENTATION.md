# Eden Nutrition 项目文档

## 1. 业务描述
Eden Nutrition 是一个专注于营养品和健康生活方式的综合性电子商务平台。系统旨在为用户提供从浏览、选择到购买营养补给品、健康食品乃至预订健康疗养房型的全流程服务。平台不仅支持普通商品的销售，还集成了秒杀活动、优惠券发放、用户积分等营销功能，以提升用户活跃度和复购率。

## 2. 流程分析（用户购物流程）
1.  **浏览商品**：用户进入首页，通过搜索或分类导航（如：营养补充剂、健康食品、疗养住宿）查找商品。
2.  **商品详情**：查看由于富文本和多图展示的商品详情，了解规格、价格、库存及用户评价。
3.  **加入购物车/立即购买**：用户通过选择规格将商品加入购物车，或直接发起购买流程。
4.  **下单结算**：确认收货地址，选择优惠券（如有），确认订单金额。
5.  **支付流程**：对接第三方支付（模拟），完成付款。
6.  **订单履约**：后台管理员发货，用户查看物流状态。
7.  **确认收货与评价**：用户收到商品后确认收货，并未商品打分评价。
8.  **售后服务**：支持退换货申请及处理。

## 3. 高阶需求设想
*   **高并发支持**：针对秒杀场景（如限时抢购热门营养品），系统需设计缓存、限流及异步处理机制，保证系统在高负载下的稳定性。
*   **安全性**：全站采用 HTTPS，用户敏感信息加密存储。使用 JWT 进行无状态认证，结合 Spring Security 实现细粒度的权限控制。
*   **扩展性**：采用模块化设计（Controller-Service-Dao），未来可轻松拆分为微服务架构（User Service, Product Service, Order Service）。
*   **多端适配**：后端 API 需支持 Web端、移动端H5及未来可能的小程序接入。
*   **数据一致性**：在库存扣减、订单生成等关键环节，需保证数据的一致性（使用事务或分布式事务方案）。

## 4. 系统用例图
*由于文本限制，以下为用例描述*
*   **普通用户**：注册/登录、浏览商品、搜索商品、管理购物车、下单、支付、查看订单、发表评价、管理收货地址、领取优惠券。
*   **管理员**：商品管理（上架/下架/编辑）、分类管理、订单管理（发货/退款处理）、用户管理、营销管理（发布秒杀/优惠券）、查看销售报表。

## 5. 框架选型
### 后端
*   **核心框架**：Spring Boot 2.7.18
*   **ORM框架**：MyBatis + MyBatis-Plus (简化CRUD)
*   **数据库**：MySQL 8.0
*   **缓存**：Redis (用于 Session 共享、缓存热点数据、秒杀库存)
*   **消息队列**：RabbitMQ (用于订单超时取消、削峰填谷)
*   **安全框架**：Spring Security + JWT
*   **API文档**：Swagger / Knife4j
*   **工具库**：Lombok, Hutool

### 前端
*   **框架**：React 18
*   **构建工具**：Vite
*   **UI库**：Tailwind CSS / Ant Design (假设)
*   **状态管理**：Redux Toolkit
*   **HTTP客户端**：Axios

## 6. 架构设计
系统采用经典的分层架构设计：
*   **表现层 (Controller)**：处理 HTTP 请求，进行参数校验，转换数据格式。
*   **业务层 (Service)**：处理核心业务逻辑，如订单状态流转、库存检查等。事务控制在此层实现。
*   **持久层 (Mapper/DAO)**：负责与 MySQL 数据库交互，执行 SQL 语句。
*   **公共模块 (Common)**：定义全局异常处理、统一响应结果、工具类等。

## 7. 产品信息需求精化
针对“营养品”及扩展品类（服装、房型），产品信息需包含：
*   **基础信息**：名称、副标题（卖点）、所属分类、价格（原价/售价）、库存。
*   **展示信息**：主图、轮播图（JSON格式存储）、详情描述（富文本，支持图文混排）。

*   **状态信息**：上架/下架状态、是否新品、是否热门、审核状态。

## 9. 功能迭代设计 (Category Management Design)

### 9.1 背景
当前系统无法在管理端进行商品分类的新增与维护，导致上架新商品时受限于初始化 SQL 数据。需增加完整的分类管理功能。
更多设计细节请参考: [FEATURE_CATEGORY_MANAGEMENT_DESIGN.md](FEATURE_CATEGORY_MANAGEMENT_DESIGN.md)

### 9.2 需求概要
1.  **分类增删改查 (CRUD)**：
    *   新增分类（支持一级分类及子分类）。
    *   编辑分类（名称、排序、图标）。
    *   删除分类（需校验是否存在关联商品或子分类）。
    *   停用/启用分类状态。
2.  **树形展示**：以层级结构展示所有分类，直观管理父子关系。

### 9.3 接口与页面
*   **API**: `POST /category/create`, `PUT /category/update`, `DELETE /category/delete/{id}`
*   **Frontend**: 新增页面 `src/pages/Product/Category.tsx`
